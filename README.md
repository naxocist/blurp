# Available commands

### General
- /anime - get random anime from MAL database</li>
- /expression - show your emotions through anime gifs</li>
- /action - express action via a gif on other members</li>
- /art - random anime art on certain style</li>

### Minigames
- /cycle - assigned an anime for your friends and let them guess that</li>
- /clues - guess a random anime based on revealing clues</li>
- /whatnum - guess a random number</li>
